## 一、各题核心考点

### 3.2.1 — 图像分类（ResNet / ImageNet）

| 考点 | 代码 |
|------|------|
| 加载 ONNX 模型 | `ort.InferenceSession('resnet50-v1-7.onnx')` |
| 打开图片并转 RGB | `Image.open('img_test.jpg').convert('RGB')` |
| 调用预处理函数 | `preprocess_image(image)` |
| 读取标签文件 | `open('labels.txt', 'r')` |
| 执行推理 | `session.run([output_name], {input_name: input})` |
| 应用 softmax | `scipy.special.softmax(output, axis=-1)` |
| 取 Top-5 索引 | `np.argsort(result)[::-1][:5]` |

**预处理流程：**
1. resize 到 256×256
2. 中心裁剪到 224×224
3. 归一化（除以 255，减均值，除以标准差）
4. HWC → CHW（`np.transpose`）
5. 增加 batch 维度（reshape 为 `(1, C, H, W)`）

### 3.2.2 — 手写数字识别（MNIST）

| 考点 | 代码 |
|------|------|
| 加载 ONNX 模型 | `ort.InferenceSession('mnist.onnx')` |
| 转灰度图 | `Image.open('img_test.png').convert('L')` |
| 调整尺寸到 28×28 | `img.resize((28, 28), Image.ANTIALIAS)` |
| 转 numpy float32 | `np.array(img, dtype=np.float32)` |
| 添加 batch 维度 | `np.expand_dims(img_data, axis=0)` |
| 添加 channel 维度 | `np.expand_dims(img_data, axis=1)` |
| 准备输入字典 | `{session.get_inputs()[0].name: input_data}` |
| 执行推理取结果 | `session.run(None, ort_inputs)` |
| 预测类别 | `np.argmax(ort_outs[0])` |

**注意：** MNIST 模型输入 shape 为 `(1, 1, 28, 28)`，灰度图只有 1 个通道。

### 3.2.3 — 人脸情感识别（FER+）

| 考点 | 代码 |
|------|------|
| 情感映射表（数字→名称） | `{0: 'neutral', 1: 'happiness', 2: 'surprise', 3: 'sadness', 4: 'anger', 5: 'disgust', 6: 'fear', 7: 'contempt'}` |
| 加载 ONNX 模型 | `ort.InferenceSession('emotion-ferplus.onnx')` |
| 调用预处理 | `preprocess('img_test.png')` |
| 执行推理 | `ort_session.run(None, ort_inputs)` |
| 预测情感索引 | `np.argmax(ort_outs[0])` |
| 查找情感名称 | `emotion_table[predicted_label]` |

**易错点：**
- `emotion_table` 必须是 `{数字: 名称}` 方向，不能反写成 `{名称: 数字}`
- `input_data` 必须经过 `preprocess()` 处理为 numpy 数组，不能直接传 PIL 图像对象

**预处理流程：**
1. 转灰度图（`convert('L')`）
2. resize 到 64×64
3. 转 float32 numpy 数组
4. 添加 batch 维度和 channel 维度
5. 校验 shape == `(1, 1, 64, 64)`

### 3.2.4 — 花卉分类 + 置信度百分比输出

| 考点 | 代码 |
|------|------|
| 加载 ONNX 模型 | `ort.InferenceSession('flower-detection.onnx')` |
| 读取标签文件 | `open('labels.txt', 'r')` |
| 打开图片 | `Image.open('flower_test.png').convert('RGB')` |

| 执行推理 | `session.run([output_name], {input_name: processed_image})[0]` |
| 应用 softmax | `scipy.special.softmax(output, axis=-1)` |
| 预测类别索引 | `np.argmax(accuracy)` |
| 转换为百分比 | `accuracy[0][predicted_idx] * 100` |
| 获取类别标签 | `labels[predicted_idx]` |

**输出格式：** `Predicted class: roses, Accuracy: 92.35%`

### 3.2.5 — 目标检测（RFB / 人脸检测）

| 考点 | 代码 |
|------|------|
| 读取类别标签 | `[name.strip() for name in open('voc-model-labels.txt')]` |
| 创建 ONNX 会话 | `ort.InferenceSession('version-RFB-320.onnx')` |
| 获取输入名称 | `ort_session.get_inputs()[0].name` |
| 创建输出目录 | `os.makedirs('detect_imgs_results_onnx', exist_ok=True)` |
| 读取图片（BGR） | `cv2.imread(os.path.join('imgs', image_path))` |
| resize 到 320×240 | `cv2.resize(orig_image, (320, 240))` |
| BGR 转 RGB | `cv2.cvtColor(image, cv2.COLOR_BGR2RGB)` |
| 归一化 | `(image - mean) / 128.0`，其中 `mean = np.array([127, 127, 127])` |
| HWC → CHW | `image.transpose(2, 0, 1)` |
| 增加 batch 维度 | `np.expand_dims(image, axis=0)` |
| 转 float32 | `image.astype(np.float32)` |
| 执行推理 | `ort_session.run(None, {input_name: image})` |
| 后处理（NMS） | `predict(orig_image.shape[1], orig_image.shape[0], confidences, boxes)` |
| 画框并保存 | `cv2.rectangle` + `cv2.imwrite` |

**`predict()` 函数逻辑：**
1. 按置信度阈值过滤检测框
2. 执行 NMS（非极大值抑制）去除重叠框
3. 将归一化坐标缩放回原图尺寸

## 二、通用考点归纳

### ONNX Runtime 推理三步模板

```python
# 1. 加载模型
session = ort.InferenceSession('model.onnx')

# 2. 获取输入输出名称
input_name = session.get_inputs()[0].name
output_name = session.get_outputs()[0].name

# 3. 执行推理
output = session.run([output_name], {input_name: input_data})[0]
# 或：output = session.run(None, {input_name: input_data})
```

### 图像预处理维度变换

```python
# PIL → numpy
img_data = np.array(img, dtype=np.float32)

# HWC → CHW
img_data = img_data.transpose(2, 0, 1)       # 彩色图（H,W,C）→（C,H,W）

# 添加 batch 维度
img_data = np.expand_dims(img_data, axis=0)  # → (1, C, H, W)
# 或
img_data = img_data.reshape((1,) + img_data.shape)
```

### 常用后处理函数

| 函数 | 用途 |
|------|------|
| `np.argmax(output)` | 取概率最大的类别索引 |
| `np.argsort(output)[::-1][:5]` | 取 Top-5 索引（降序） |
| `scipy.special.softmax(output, axis=-1)` | 将 logits 转为概率 |
| `accuracy[0][idx] * 100` | 概率转百分比 |

### 各题模型输入 shape 对比

| 题目 | 模型 | 输入 Shape |
|------|------|------------|
| 3.2.1 | ResNet（ImageNet） | `(1, 3, 224, 224)` |
| 3.2.2 | MNIST | `(1, 1, 28, 28)` |
| 3.2.3 | FER+（情感） | `(1, 1, 64, 64)` |
| 3.2.4 | 花卉分类 | `(1, 3, 224, 224)` |
| 3.2.5 | RFB（目标检测） | `(1, 3, 240, 320)` |

## 三、高频易错点

1. **预处理函数忘记调用**：定义了 `preprocess()` 但 `input_data` 直接传 PIL 对象 → `RuntimeError`
2. **emotion_table 方向写反**：应为 `{0: 'neutral', ...}` 而非 `{'neutral': 0, ...}`
3. **softmax 轴方向**：应为 `axis=-1`（对最后一维操作）
4. **百分比计算**：`accuracy[0][idx] * 100`，注意 `[0]` 取 batch 第一个
5. **图像通道顺序**：OpenCV 读取为 BGR，需 `cvtColor` 转 RGB 再送入模型
6. **数据类型**：推理前必须 `.astype(np.float32)`
