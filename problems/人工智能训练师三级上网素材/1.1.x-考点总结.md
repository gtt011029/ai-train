## 四、数据清洗与预处理

### 4.1 删除缺失值

```python
data = data.dropna()         # 删除含缺失值的行
data = data.dropna(axis=0)   # 同上，axis=0 表示按行删除
```

### 4.2 数据类型转换

```python
data["Age"] = data["Age"].astype(int)
data["Speed"] = data["Speed"].astype(float)
data["PurchaseAmount"] = data["PurchaseAmount"].astype(float)
```

### 4.3 缺失值填充（前向/后向填充）

```python
data["Value"].fillna(method='ffill', inplace=True)   # 前向填充 Forward Fill
data["Value"].fillna(method='bfill', inplace=True)   # 后向填充 Backward Fill
```

> **注意**：先 ffill 后 bfill，确保首尾缺失也被填充。

### 4.4 删除列

```python
cleaned_data = data.drop(columns=["is_abnormal"])
cleaned_data = data.drop(columns=["col1", "col2", "col3"])
```

### 4.5 保存数据

```python
data.to_csv("cleaned_xxx.csv", index=False)   # index=False 不保存行索引
```

## 五、异常值处理

### 5.1 使用 `np.where()` 标记/分类（★高频考点）

```python
# 语法：np.where(条件, 条件为True时的值, 条件为False时的值)
data["RiskLevel"] = np.where(data["DaysInHospital"] > 7, "高风险患者", "低风险患者")

# 标记异常值（多条件）
data["is_abnormal"] = np.where(
    ((data["SensorType"] == 'Temperature') & ((data["Value"] < -10) | (data["Value"] > 50)))
    | ((data["SensorType"] == 'Humidity') & ((data["Value"] < 0) | (data["Value"] > 100))),
    True,
    False,
)
```

### 5.2 使用 `between()` 过滤异常值（★高频考点）

```python
# between(a, b) 等价于 a <= x <= b（闭区间）
data = data[
    (data["Age"].between(18, 70))
    & (data["Speed"].between(0, 200))
    & (data["TravelDistance"].between(1, 1000))
    & (data["TravelTime"].between(1, 1440))
]
```

### 5.3 数据合理性审核（创建布尔列）

```python
data["is_age_valid"] = data["Age"].between(18, 70)
data["is_income_valid"] = data["Income"] > 2000
data["is_loan_amount_valid"] = data["LoanAmount"] < (data["Income"] * 5)
data["is_credit_score_valid"] = data["CreditScore"].between(300, 850)

# 所有条件同时满足
validity_checks = data[["is_age_valid", "is_income_valid", ...]].all(axis=1)
data["is_valid"] = validity_checks

# 筛选不合理数据
invalid_rows = data[~data["is_valid"]]
cleaned_data = data[data["is_valid"]]
```

## 六、数据标准化（Z-score）（1.1.4 重点）

**公式**：`z = (x - μ) / σ`，使数据均值为 0、标准差为 1。

```python
data["PurchaseAmount"] = (data["PurchaseAmount"] - data["PurchaseAmount"].mean()) / data["PurchaseAmount"].std()
data["ReviewScore"] = (data["ReviewScore"] - data["ReviewScore"].mean()) / data["ReviewScore"].std()
```

## 七、数据统计与分析

### 7.1 `value_counts()`（★高频考点）

统计 Series 中各唯一值出现的次数，返回 `pandas.Series`（索引为唯一值，值为频次，默认降序）。

```python
risk_counts = data["RiskLevel"].value_counts()
traffic_event_counts = data["TrafficEvent"].value_counts()
age_group_counts = data["AgeGroup"].value_counts()
age_group_counts = data["AgeGroup"].value_counts().sort_index()  # 按索引排序
```

### 7.2 `groupby()` 分组统计（★高频考点）

```python
# 单列分组 + 多聚合函数（返回 DataFrame，列名为 count、mean）
sensor_stats = data.groupby(data["SensorType"])["Value"].agg(['count', 'mean'])

# 多列分组 + 求均值 + 透视（unstack 将内层索引转为列）
location_stats = data[data['SensorType'].isin(['Temperature', 'Humidity'])] \
    .groupby(['Location', 'SensorType'])['Value'].mean().unstack()

# 分组 + 均值
gender_stats = data.groupby(["Gender"]).mean()
gender_purchase_mean = data.groupby(["Gender"])["PurchaseAmount"].mean()

# 分组 + 自定义函数（lambda）
bmi_risk_rate = data.groupby(data["BMIRange"])["RiskLevel"].apply(
    lambda x: (x == "高风险患者").mean()
)
```

### 7.3 `isin()` 多值过滤

```python
location_stats = data[data['SensorType'].isin(['Temperature', 'Humidity'])]
```

### 7.4 统计 boolean 列中 True 的数量

```python
# Python 中 True=1，False=0，sum() 即为 True 的数量
print("异常值数量:", data["is_abnormal"].sum())
```

## 八、区间划分 `pd.cut()`（★高频考点）

将连续数值划分为离散区间（分箱）。

```python
# 语法
pd.cut(x=数据列, bins=区间边界列表, labels=标签列表, right=False)
# right=False 表示左闭右开区间 [a, b)

# BMI 分区
bmi_bins = [0, 18.5, 24, 28, np.inf]
bmi_labels = ["偏瘦", "正常", "超重", "肥胖"]
data["BMIRange"] = pd.cut(x=data["BMI"], bins=bmi_bins, labels=bmi_labels, right=False)

# 年龄分区（通用写法）
age_bins = [18, 26, 36, 46, 56, 66, np.inf]
age_labels = ["18-25", "26-35", "36-45", "46-55", "56-65", "65+"]
data["AgeGroup"] = pd.cut(x=data["Age"], bins=age_bins, labels=age_labels, right=False)
```

## 九、各题核心考点速查

### 1.1.4 用户行为数据处理
- `dropna(axis=0)` 删除缺失行

- `between()` 过滤异常值

- `pd.cut()` 年龄分组 + `value_counts().sort_index()`

### 1.1.5 车辆交通数据处理
